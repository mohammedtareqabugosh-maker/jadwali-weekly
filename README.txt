# جدولي الأسبوعي — تطبيق قابل للإضافة للشاشة الرئيسية

## تشغيله على iPhone
1. ارفع محتويات هذا المجلد كاملة إلى استضافة HTTPS ثابتة (مثل GitHub Pages أو Netlify).
2. افتح رابط `index.html` المنشور في Safari على الآيفون.
3. اضغط زر المشاركة (المربع مع السهم للأعلى).
4. اختر **إضافة إلى الشاشة الرئيسية** ثم اضغط **إضافة**.

## ملاحظات
- البيانات تحفظ محلياً على نفس الجهاز والمتصفح.
- ملفات التطبيق مهيأة للعمل كتطبيق ويب تقدمي (PWA) وتدعم التخزين المؤقت بعد أول زيارة عند الاستضافة عبر HTTPS.
- ملف HTML وحده لا يكفي لتفعيل إضافة الشاشة الرئيسية بشكل موثوق؛ يلزم نشره على رابط HTTPS.
- لا توجد مزامنة سحابية؛ حذف بيانات Safari أو تغيير المتصفح/الجهاز قد يؤدي لفقدان البيانات.
