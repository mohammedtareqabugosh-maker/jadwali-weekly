# جدولي الأسبوعي

تطبيق ويب تقدمي (PWA) عربي، يعمل داخل المتصفح دون خادم. يوجد منه نسختان مستقلتان:

- **النسخة الجاهزة:** [`ready/`](./ready/) — جدول معبّأ بالجدول الأسبوعي الحالي.
- **النسخة الفارغة:** [`blank/`](./blank/) — جدول فارغ يملؤه المستخدم بجدوله الخاص. مناسبة للإرسال إلى الآخرين.

## الفصل بين النسختين

- كل نسخة في مجلد مستقل وتحمل ملف `index.html` و`manifest.webmanifest` و`sw.js` الخاصة بها.
- تحفظ كل نسخة بياناتها في المتصفح بمفتاح مختلف (`weekly-planner-ready-v1` و`weekly-planner-blank-v1`)، ومفتاح كاش الوجبات أيضًا مختلف، فلا تختلط البيانات بين النسختين على الجهاز نفسه.
- لكل نسخة اسم وأيقونة تثبيت مستقلان على الشاشة الرئيسية.

## التشغيل والتثبيت

الملفات HTML/CSS/JS ثابتة. انشرها على أي استضافة HTTPS (مثل GitHub Pages)، ثم افتح الرابط في Safari أو Chrome وأضفه إلى الشاشة الرئيسية. الأيقونات مشتركة في مجلد `icons/`.

## ملاحظات

- لا توجد مزامنة سحابية؛ حذف بيانات المتصفح أو تغيير الجهاز قد يؤدي إلى فقدان البيانات.
- الربط مع تطبيق «مساعدي الغذائي» مؤجل، ولم يُدمج في هذا الإصدار. ملف `shared_schedule.sql` محفوظ للمرحلة اللاحقة فقط.
- تطبيق React الخاص بـ Kimi موجود في فرع منفصل باسم `kimi-react-app`، ولا يُدمج مع هاتين النسختين.
